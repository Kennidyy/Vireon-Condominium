# Vireon Condominium

A condominium management platform focused on centralizing daily operations and improving communication between residents and administrators.

## About

The idea behind Vireon Condominium came from my experience living in a condominium where many processes are managed through informal communication channels.

This project explores how a dedicated platform can organize these processes into a more accessible and structured system.
